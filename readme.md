# 神经网络与多项式回归：实验图表的数学解读

> 这份文档面向**完全没参与过这个项目的人**。我们从最根本的问题讲起，一步步建立起读懂每一张图所需的全部概念。你不需要预先了解神经网络或本项目的任何细节。

---

## 第一部分：我们到底在研究什么问题？

### 1.1 一个朴素的直觉

神经网络（Neural Network，简称 NN）是当今最强大的预测工具之一，但它常被称为"黑箱"——我们知道它有效，却不容易说清它内部在做什么。

多项式（Polynomial）则完全相反。形如

$$
f(x) = \beta_0 + \beta_1 x + \beta_2 x^2 + \beta_3 x^3 + \cdots
$$

的多项式是数学里最透明、最好理解的函数：每一项的含义、每个系数的作用都一清二楚。

**本项目的核心问题是：神经网络是不是在"偷偷地"做多项式回归？** 换句话说，一个训练好的神经网络，能不能被一个多项式很好地替代？如果能，那"黑箱"就被打开了——我们可以用透明的多项式来理解不透明的网络。

### 1.2 这个直觉的数学来源

这个想法不是凭空来的。神经网络的每一层做两件事：先做一个**线性变换**（加权求和），再过一个**激活函数** $g$（一个非线性的"弯曲"）。常见的激活函数如 softplus、tanh、sigmoid，都是**光滑函数**——意味着它们可以做泰勒展开：

$$
g(u) = g(0) + g'(0)\,u + \frac{g''(0)}{2!}u^2 + \frac{g'''(0)}{3!}u^3 + \cdots
$$

这正是关键。**泰勒展开把一个光滑的非线性函数写成了多项式的形式**。如果网络每一层的激活函数都能用多项式近似，那整个网络——作为这些层的复合——原则上也应该能用一个多项式近似。

但这里有个"但是"：泰勒展开只在 $u$ **靠近展开点**（这里是 0）时才准确。如果 $u$ 跑得太远，高次项 $u^k$ 会爆炸式增长，近似彻底失效。这个"成立的条件"和"失效的边界"，正是本项目要用实验去探测的东西。

## 第二部分：三个被反复比较的模型

整个实验里，我们始终在比较**三个模型**对同一份数据的表现。理解这三者是读懂所有图的前提。

| 模型 | 全称 | 它是什么 |
|------|------|---------|
| **NN** | Neural Network | 训练好的神经网络。这是我们要"解释"的对象。 |
| **FullPR** | Full Polynomial Regression | 直接用多项式去拟合数据。把数据喂给一个多项式，让它学最佳系数。 |
| **LayerTaylorPR (LTPR)** | Layer-wise Taylor Polynomial Regression | 把训练好的 NN **逐层泰勒展开**，符号化地推导出一个多项式。不重新拟合数据，而是直接从网络权重"翻译"出多项式。 |

**两种多项式的区别非常重要：**

- **FullPR** 是"独立的竞争者"：它不看 NN，只看数据，自己学一个多项式。
- **LTPR** 是"NN 的翻译"：它不看数据的标签，只看 NN 的内部权重，试图用多项式复刻 NN 本身。

所以：
- "NN 和 **FullPR** 像不像" 回答的是：*神经网络和一个直接拟合的多项式，是否殊途同归？*
- "NN 和 **LTPR** 像不像" 回答的是：*泰勒展开这套"翻译"方法到底准不准、什么时候会失效？*

## 第三部分：我们如何"测量"模型之间的关系？

要画图，先要有可量化的指标。这里有三类。

### 3.1 性能指标：MSE（均方误差）

衡量一个模型预测得准不准，用**均方误差**：

$$
\mathrm{MSE} = \frac{1}{n}\sum_{i=1}^{n}\bigl(\hat{y}_i - y_i\bigr)^2
$$

其中 $\hat y_i$ 是模型的预测，$y_i$ 是真实值。MSE 越小，预测越准。

图里出现的几个变体：
- `NN_mse_vs_y`：NN 的预测 vs 真实标签 → NN 准不准。
- `FPR_mse_vs_y`：FullPR 的预测 vs 真实标签 → FullPR 准不准。
- `FPR_mse_vs_NN`：FullPR 的预测 vs **NN 的预测** → FullPR 复刻 NN 的程度。
- `LTPR_mse_vs_NN`：LTPR 的预测 vs **NN 的预测** → 泰勒翻译复刻 NN 的程度。

注意后两个的"真值"换成了 NN 的输出，因为我们关心的是"像不像 NN"，而不是"准不准"。

### 3.2 性能差距：abs_rmse_gap

光看单个 MSE 不够，我们还想直接量化"两个模型表现差多少"。定义

$$
\texttt{abs\_rmse\_gap} = \bigl|\sqrt{\mathrm{MSE}_{\mathrm{NN}}} - \sqrt{\mathrm{MSE}_{\mathrm{FullPR}}}\bigr|
$$

这里取了平方根（把 MSE 变成 RMSE，与数据同量纲），再取两个模型 RMSE 的**绝对差**。这个值越小，说明两个模型"准的程度"越接近。它是后面"性能差距"轴的含义。

### 3.3 几何指标：形状距离（核心创新）

这是本项目最有特色的部分。我们不只比"准不准"，还要比**两个模型学到的函数"长得像不像"**——即它们的几何形状。

**做法：** 把每个模型在测试点上的预测，和输入拼成一个"响应曲面"上的点云。对模型 A：

$$
\text{点云}_A = \bigl\{\,(x_i,\ \hat y_i^{A})\ :\ i=1,\dots,n\,\bigr\}
$$

对模型 B 同理得到点云$_B$。两片点云的输入坐标 $x_i$ 完全相同，唯一的差别在预测值那一维。

然后用 **Procrustes 分析**测量这两片点云的形状差异。Procrustes 做三件事：

1. **平移对齐**：把两片点云的中心移到原点（消除整体位置差异）；
2. **缩放对齐**：把两片点云缩放到相同的整体尺度（消除整体放大缩小）；
3. **旋转对齐**：旋转其中一片去最佳贴合另一片。

对齐之后，计算逐点残差平方和：

$$
\texttt{shape\_distance} = \sum_{i=1}^{n}\bigl\|a_i - b_i\bigr\|^2
$$

其中 $a_i, b_i$ 是对齐后两片点云的对应点。这个值就是**形状距离**：

- 接近 0 → 两个模型学到的函数**形状几乎相同**（哪怕差一个平移或缩放）；
- 越大 → 两个模型的函数形状越不一样。

**关键理解**：形状距离"模掉了"平移、旋转、缩放。所以它衡量的是纯粹的"形状像不像"，而不是"预测值差多少"（后者是 MSE）。一个曲面平移一个常数，形状距离不变，但 MSE 会变。两者捕捉的是不同的东西。

图里的几个形状距离：
- `shape_NN_FPR_in`：NN 与 FullPR 在**数据覆盖区域内**的形状距离。
- `shape_NN_FPR_ext`：NN 与 FullPR 在**外推区域**（数据范围 2 倍之外）的形状距离。
- `shape_NN_LTPR`：NN 与 LTPR 的形状距离。
- `shape_LTPR_FPR`：两种多项式（LTPR 与 FullPR）彼此的形状距离。

### 3.4 激活改变量：act_io_sum

我们还想量化"激活函数到底给数据注入了多少非线性"。对网络的每一个激活层，看它的输入 $u$ 和输出 $g(u)$，用形状距离测量 $u \to g(u)$ 这个变换"弯曲"了多少。把所有激活层的这个量**加总**，得到 `act_io_scaled_sum`（"scaled"指输入被归一化到 $[-1,1]$）。

直觉：如果激活函数几乎是直线（弯曲很小），网络就接近线性，也就接近低阶多项式；如果激活函数被推到强烈弯曲的区域，网络注入了大量非线性。这个量是我们最初假设的"自变量"。

## 第四部分：逐张读懂"几何图"（geometry 图）

每个数据集有一张 geometry 图，含约 11 个子图，每个**点是一次独立实验**，**颜色代表激活函数**（绿=softplus，橙=tanh，深蓝=sigmoid）。下面解释每一类子图。

### 4.1 `act-change(sum) → NN-FullPR closeness(in)`
- **横轴**：激活改变总量 `act_io_scaled_sum`。
- **纵轴**：NN 与 FullPR 在数据区内的形状距离 `shape_NN_FPR_in`。
- **在问**：激活注入的非线性越多，NN 和多项式在数据区内就越不像吗？
- **怎么读**：如果是正相关（点呈上升趋势），支持"激活改变大 → 偏离多项式"；如果是负相关或杂乱，说明数据区内这个关系不成立——这正是本项目一个反直觉的发现。

### 4.2 `act-change(sum) → closeness(extrap)`
- **横轴**：同上，激活改变量。
- **纵轴**：NN 与 FullPR 在**外推区**的形状距离 `shape_NN_FPR_ext`。
- **在问**：激活改变能否预测两者在**数据之外**的分歧？
- **怎么读**：常出现**水平条带**。饱和型激活（tanh、sigmoid）在外推时趋于平坦，而多项式趋于发散，两者的差距被锁定在某个固定值，于是堆成一条横线。这是"饱和激活外推时偏离多项式"的几何指纹。

### 4.3 `NN-FullPR closeness → perf gap`（**核心图**）
- **横轴**：NN 与 FullPR 的形状距离 `shape_NN_FPR_in`。
- **纵轴**：两者的性能差距 `abs_rmse_gap`。
- **在问**：两个模型几何上越像，性能是否越接近？
- **怎么读**：如果呈清晰的**上升带**，就证明了本项目的核心命题——**形状接近 ⟹ 性能接近**。这在数学上并非自动成立（形状距离模掉了缩放，理论上形状相同的两个模型 MSE 仍可不同），所以它是一个有内容的经验发现，而非恒等式。

### 4.4 `adj-layer nonlin → NN-FullPR closeness(in)`
- **横轴**：相邻层之间的非线性程度 `act_pair_mean`。
- **纵轴**：NN-FullPR 数据区形状距离。
- 与 4.1 类似，只是用了另一种"非线性"的度量方式，作为交叉验证。

### 4.5 涉及 LayerTaylorPR 的子图
- `NN-LayerTaylorPR closeness → perf gap`：LTPR 这个"翻译多项式"和 NN 像不像，能否预测性能差距。
- `act-change → NN-LayerTaylorPR closeness`：激活改变越大，泰勒翻译越容易偏离 NN 吗？（通常是的——这就是泰勒展开失效的征兆。）
- `NN-LayerTaylorPR vs NN-FullPR`：两种"NN 的多项式代理"是否一致。
- `LayerTaylorPR-FullPR → perf gap` 和 `LayerTaylorPR-FullPR vs NN-FullPR`：两种多项式彼此的关系。

## 第五部分：逐张读懂"MSE 图"（mse 图）

每个数据集还有一张 mse 图，6 个子图，专门调查**各测量指标与 MSE 的关系**以及**模型之间的表现对比**。

### 5.1 `act-change → NN MSE(vs y)`
激活改变量 vs NN 自身的准确度。看激活注入的非线性是否影响 NN 的拟合质量。

### 5.2 `NN-FullPR closeness → FullPR MSE(vs NN)`
形状距离 vs FullPR 复刻 NN 的误差。通常是非常干净的**正相关直线**——形状越近，复刻误差越小。这验证了"形状距离"确实是个有意义的量。

### 5.3 `NN-LayerTaylorPR closeness → LTPR MSE(vs NN)`
形状距离 vs LTPR 复刻 NN 的误差。**这张图要特别小心**：LTPR 的 MSE 偶尔会爆炸到天文数字（如 $10^8$），因为泰勒展开在突触电位冲出收敛域时灾难性发散。这些爆炸点是"泰勒方法失效"的实证，但会让图变得不可读（正常点被压成贴地一条线）。

### 5.4 `NN MSE vs FullPR MSE`（带 y=x 参考线）
- **横轴**：NN 的 MSE。**纵轴**：FullPR 的 MSE。
- **对角虚线 y=x**：参考线。点落在线**下方**表示 FullPR 比 NN 准；落在**上方**表示 NN 比 FullPR 准。
- 这是两个模型准确度的直接对决。

### 5.5 `FullPR vs LayerTaylorPR`
两种多项式各自复刻 NN 的误差对比。理想情况下两者都接近 0；LTPR 偶尔的爆炸会在这里显现。

### 5.6 `NN MSE → NN-FullPR perf gap`
NN 自身的误差 vs 它和 FullPR 的性能差距。看 NN 拟合得好坏是否影响它与多项式的接近程度。

## 第六部分：读懂"总览箱线图"（overview boxplot）

箱线图（box plot）展示一个量在所有实验里的**分布**。一个箱子包含：

- **箱体**：从第 25 百分位数到第 75 百分位数（中间 50% 的数据落在这里）；
- **箱中横线**：中位数（第 50 百分位数）；
- **上下"须"**：延伸到非异常值的范围；
- **须外的圆圈**：**离群点**（异常值）。

总览图按三种激活函数各画一个箱子，展示三个量：
1. `act_io_scaled_sum`（激活改变量）：看哪种激活注入更多非线性、变异多大。
2. `shape_NN_FPR_in`（NN-FullPR 形状距离）：通常**箱体紧贴 0**，说明绝大多数情况下 NN 和多项式非常像。
3. `abs_rmse_gap`（性能差距）：通常也贴地。

**关键观察**：这些箱线图往往拖着**大量向上的离群圈**。这些就是"未收敛的训练"或"泰勒展开失效"造成的异常 run。它们提醒我们：结论应基于主体（中位数附近），而异常点要单独识别和处理。

## 第七部分：两个贯穿全局的重要现象

### 7.1 辛普森悖论（Simpson's Paradox）

当我们把**多个数据集混在一起**算相关性时，可能得到一个方向；而**分数据集单独**算时，得到相反的方向。这就是辛普森悖论。

举例：在本项目里，"激活改变 → NN-FullPR 接近度"这个关系，把所有数据集合并时是**正相关**，但每个数据集内部却是**负相关**。原因是不同数据集整体水平不同，合并时这种"组间差异"制造了虚假的趋势。

**教训**：必须分数据集报告结论，不能只看合并结果。这正是我们为什么把图按数据集拆开。

### 7.2 泰勒展开的灾难性失效

LayerTaylorPR 通过逐层泰勒展开把网络翻译成多项式。泰勒级数

$$
g(u) = \sum_{k=0}^{\infty}\frac{g^{(k)}(0)}{k!}u^k
$$

只在 $u$ 落在**收敛域**内时有效。一旦某个神经元的突触电位 $u$ 太大，高次项 $u^k$ 爆炸，整个多项式发散，预测值可达 $10^8$ 量级——而 NN 本身的输出只有 $0.00x$ 量级。

这种失效是**稀有但灾难性**的：绝大多数 run 里 LTPR 完美复刻 NN（误差 $10^{-9}$），偶尔几次彻底爆炸。这恰恰印证了原始论文（Morala et al., 2021）的核心警告——泰勒近似有明确的适用边界。在分析时，这些爆炸值应被识别为"失效"单独统计，而不是当作正常数值参与平均或相关性计算。

## 第八部分：一页纸总结

| 你想知道 | 看哪张图 | 关键结论 |
|---------|---------|---------|
| NN 和多项式像不像？ | overview 箱线图中间一张 | 箱体贴 0，**大多数时候很像** |
| 形状近能否预测性能近？ | geometry 图的 `closeness → perf gap` | **能**，呈上升带（核心命题） |
| 激活影响在哪里体现？ | geometry 图的 `closeness(extrap)` | 在**外推区**，饱和激活形成水平条带 |
| 泰勒翻译可靠吗？ | mse 图的 `LTPR MSE(vs NN)` | 大多完美，**偶尔灾难性爆炸** |
| NN 和 FullPR 谁更准？ | mse 图的 `NN MSE vs FullPR MSE`（y=x 线） | 看点在对角线哪一侧 |

**一句话总括**：本项目用"形状距离"这把几何尺子，证明了神经网络在很大程度上等价于一个多项式（形状近、性能也近），并精确刻画了这种等价**何时成立、何时失效**——失效主要发生在外推区（饱和激活）和泰勒展开冲出收敛域时。这把"神经网络是不是在做多项式回归"这个模糊直觉，变成了可测量、可证伪、有边界的科学结论。

---

*注：本文中的"形状距离"基于 Procrustes 分析，"激活改变量"基于逐层输入输出的形状变化，"逐层泰勒展开"将任意深度网络符号化地复合为单个多项式。所有指标均在多次重复实验（不同随机初始化）下统计，以反映训练随机性。*
